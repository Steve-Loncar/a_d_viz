# A&D Viz App (v2)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
streamlit run app/app.py
```

## Data

Place your workbook at:

`data/a_d_database.xlsx`

Or use the file uploader in the UI.
